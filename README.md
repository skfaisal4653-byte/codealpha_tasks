# CodeAlpha Python Tasks

This repository contains three Python projects completed as part of the CodeAlpha internship task submission.

## Projects

### 1. Hangman Game
A word-guessing game in which the player tries to guess a randomly selected word within a limited number of incorrect attempts.

**Technologies:** Python

**Project folder:** `Hangman-Game/`

### 2. Stock Portfolio Tracker
A Python program that tracks selected stocks and calculates investment values based on stock prices and quantities.

**Technologies:** Python

**Project folder:** `Stock-Portfolio-Tracker/`

### 3. Simple Chatbot
A basic rule-based chatbot that responds to predefined user messages using conditional statements and functions.

**Technologies:** Python

**Project folder:** `Simple-Chatbot/`

## How to Run

1. Install Python 3 if it is not already installed.
2. Download or clone this repository.
3. Open the folder for the project you want to run.
4. Run the corresponding Python file using:

```bash
python filename.py
```

Replace `filename.py` with the actual Python filename for your chosen project.
